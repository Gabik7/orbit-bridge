# ORBIT Bridge

Inštalačné balíčky appky **ORBIT Bridge**, ktorá tvojmu ORBIT-u sprístupní vybrané priečinky, stav počítača
a tvoj Claude Code na počítači. Všetko ostatné (zdrojový kód, nastavenie) je v ORBIT.

## Stiahnutie

Najnovšia verzia je v [Releases](../../releases/latest):

- **macOS:** `ORBIT-Bridge.dmg`
- **Windows:** `ORBIT-Bridge-Setup.exe` (zatiaľ neoverené na skutočnom počítači)

Najjednoduchšie je stiahnuť ju priamo z ORBIT: **Pripojenia → Počítač → Stiahnuť**.

## Ako začať

1. Stiahni a otvor ORBIT Bridge.
2. V lište (macOS) alebo v oblasti oznámení (Windows) sa objaví ikona ORBIT.
3. Spáruj ho: appka ti ukáže kód, potvrď ho v ORBIT.
4. Vyber priečinky, ktoré ORBIT uvidí. Nič iné nevidí.
